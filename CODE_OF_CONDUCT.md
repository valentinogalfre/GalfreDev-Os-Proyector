# Código de convivencia

Este proyecto lo hacen personas con distintos niveles de experiencia, de distintos lugares y
con distintas ideas. Queremos que cualquiera pueda sumarse sin sentirse de más.

## Lo que esperamos

- Tratar bien a todos, sobre todo a quien recién empieza.
- Discutir ideas, no personas. Una crítica a un pull request es sobre el código.
- Aceptar que te digan que no, y explicar bien cuando decís que no.
- Dar crédito a quien hizo el trabajo.

## Lo que no va

- Insultos, burlas, acoso o comentarios discriminatorios de cualquier tipo.
- Publicar datos privados de otra persona.
- Insistir con algo después de que te pidieron que pares.
- Spam o autopromoción que no tenga que ver con el proyecto.

## Qué pasa si alguien no lo cumple

Quien mantiene el proyecto puede borrar comentarios, cerrar issues o pull requests y, si hace
falta, bloquear a alguien del repositorio. Primero se avisa, salvo que sea algo grave.

Para reportar algo, escribí a quien mantiene el proyecto por privado desde su perfil de
GitHub ([@valentinogalfre](https://github.com/valentinogalfre)). Se trata con discreción.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/),
versión 2.1.
